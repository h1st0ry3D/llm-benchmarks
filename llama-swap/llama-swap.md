# `llama-swap.html` usage

A single self-contained static HTML file that renders `llama-swap.yaml` as a sortable
model-comparison table. No build step, no dependencies installed — the YAML parser
(js-yaml) is inlined.

## What it shows

One row per model, columns extracted from each entry's `name` (the model id) and
`description` string:

| Column | Source | Notes |
|--------|--------|-------|
| `#`    | order in yaml | row number |
| Model  | entry key / `name` | the `modelid_<ctx>k[-vision]` id |
| Score  | `description` → `score:` | HumanEval %, sorted numerically |
| TPS    | `description` → `tps:` | tokens/sec, sorted numerically |
| Ctx    | `description` → `ctx:` | context size (`32k`, `1m`…), sorted numerically (`1m` = 1024k) |
| Vision | `description` → `vision:` | `yes` / `no` (omitted = no) |
| Quant  | `description` → `quant:` | e.g. `q4_k_l`, `iq2_m` |
| Reasoning | `description` → `reasoning:` | `on` / `off` |
| Description | full `description` | raw, for filtering |

- **★** marks the best value per metric (Score / TPS / Ctx) so you can see
  "best in what" at a glance.
- Missing values show `—` and sink to the bottom when sorting.

## How to open

### A. Served over HTTP (recommended — auto-updates)

Browsers block `fetch()` of local files, so double-clicking the file will NOT load
the yaml. Serve the folder instead:

```bash
cd /home/llm/agent
python3 -m http.server 8000
```

Then open: **http://localhost:8000/llama-swap.html**

- Loads `llama-swap.yaml` automatically on open.
- Loads `llama-swap.yaml` once on open. Refresh the **browser** to pick up edits you save to the yaml.
- The `meta` line shows `source: live file` and the routing-member count.

### B. Offline (file://)

Just open `llama-swap.html` directly (double-click). It starts **empty** with a
prompt, because nothing is embedded. To load data:

- Use the **"load yaml"** file button (top bar) and pick `llama-swap.yaml`.
- Re-pick the yaml with the **"load yaml"** button to load edits you made on disk.
- The `meta` line will show `source: loaded: <filename>`.

> The HTML never contains a copy of your yaml — it always reads it live (served)
> or from the file you pick (offline). Keep the HTML next to `llama-swap.yaml`
> when serving.

## Interactions

- **Sort**: click any column header to sort. Click again to flip direction
  (arrow ▼/▲ shows the active column). Numeric columns sort numerically;
  `Model` / `Quant` / `Description` sort alphabetically; `Vision` / `Reasoning`
  rank yes/on above no/off.
- **Reload**: served mode reads the yaml once on open — refresh the browser tab to pick up edits; `file://` mode re-reads the picked file when you re-select it with the **"load yaml"** button.
- **Best**: the ★ in Score / TPS / Ctx columns marks the top model for that metric.
- **Errors**: if the yaml can't be read or has a syntax error, a red dialog shows the message (e.g. `YAML parse error: …`). Click **OK** to dismiss. A successful load clears it.

## Regenerating

The HTML is generated by `/tmp/gen_html.py` (reads `llama-swap.yaml`, inlines
js-yaml + the parser). Re-run it if you change the generator or want to re-embed
a fresh snapshot:

```bash
python3 /tmp/gen_html.py
```

(Not needed for normal yaml edits — those are picked up live when served.)
